# Octo Labs — Landing Page

Landing page oficial da Octo Labs: SaaS de landing pages, com seção sobre a expansão futura para placas NFC.

## Estrutura

```
octo-labs/
├── index.html
├── assets/
│   ├── css/style.css
│   ├── js/main.js
│   └── img/logo.jpg
└── README.md
```

## Como usar

Basta abrir `index.html` no navegador — não há build nem dependências.

Para hospedar, suba a pasta inteira em qualquer serviço de hosting estático (Vercel, Netlify, GitHub Pages, etc).
