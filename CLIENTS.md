# Clientes / Leads — Octo Labs

Template inicial para acompanhar clientes e leads. Atualize esta tabela conforme novos contatos surgirem.

## Como usar

- **Status sugeridos:** `Lead` · `Em conversa` · `Proposta enviada` · `Fechado` · `Em produção` · `Entregue` · `Perdido`
- Mantenha a data sempre no formato `AAAA-MM-DD`.
- Adicione uma nova linha por cliente/lead, na ordem que preferir (por data ou por status).
